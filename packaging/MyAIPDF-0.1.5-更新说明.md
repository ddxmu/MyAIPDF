# MyAIPDF 0.1.5

本版完成截图中指定的两项灰色功能，并增加水印页返回箭头。其余功能没有批量改成“可用”。

- **PostScript / EPS**：可选择页码、分辨率及格式。PS 输出多页文件；EPS 每页一个文件。保留可见页面版式，文字、矢量会转成 JPEG 图像。不是可编辑矢量或印刷色彩管理导出。
- **使用证书加密**：选择收件人公钥证书、核对指纹、选择权限，确认后另存加密副本。支持 RSA 2048–4096 位和 AES-256。打开副本需要对应的 `.p12/.pfx` 私钥及其密码，私钥密码不写入设置。普通保存与自动恢复仍保持加密，原件不会自动覆盖。
- **水印去除返回箭头**：标题左侧“‹ 返回工具”回到工具列表，不清空分析、不删除水印、不改动文档。

证书功能限定为 `adbe.pkcs7.s5/AESV3` 和 AES-256-CBC 的 RSA CMS；所有收件人共享只读/打印或完全控制权限。拒绝 CA、仅签名、未生效或过期证书及已签名 PDF 重写。不支持旧版 RC2/3DES、EC、硬件钥匙串解密、独立历史修订打开或在线吊销验证；权限约束取决于阅读器。

更新继续使用手动“检查更新 → 下载更新 → 安装并重启”。0.1.4 可用精确匹配的增量包，旧版可使用完整包。先保存未保存的文件；安装保留旧程序备份及个人设置。桌面交付目录固定为 `MyAIPDF/0.1.5`，历史版本不覆盖。

本次使用合成文档测试，不上传或修改个人 PDF；按 PDF 验证流程检查了独立解密后的页面。OpenSSL 双向 CMS 互操作和 Apache PDFBox 3.0.8 解密通过。参考：[PDF 公钥加密说明](https://pdfa.org/quirks-of-pdf-public-key-encryption/)、[PDFBox 官方发行](https://pdfbox.apache.org/download.html)。

安装包面向 Apple Silicon Mac，使用本机临时签名；没有 Apple 开发者公证。首次打开如被 macOS 拦截，请在系统“隐私与安全性”中确认来源后打开。
