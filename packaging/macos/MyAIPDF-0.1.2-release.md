# MyAIPDF 0.1.2

## 界面与文字编辑

- 修正中文、英文、数字的基线与黑体行距；标题、菜单、按钮使用一致的字重，长文件名／路径不再覆盖右侧页数和文件大小。
- 顶部“编辑”直接进入文字与图片编辑，点击页面文字框后可修改内容、字号、加粗、倾斜、颜色等；新增“应用修改／取消输入”。
- ⌘S 自动提交正在输入的文字。关闭窗口、退出和更新安装会识别尚未提交的输入；缺字或失败时保留草稿，不覆盖目标文件。
- 中文缺字时嵌入 OFL 黑体 TrueType 子集与 Unicode 映射，支持超过 240 个不同汉字，保存重开后可再次编辑。中文长段落按框宽换行，保留手动换行。

保留 AI 助手、红紫 DPF 图标和关于页面的 GitHub 更新入口。源代码与该版本安装包一起留存。

验证：整套工作区测试与严格检查通过；独立 PDF 工具核对中文修改／重开／再次编辑并检查渲染画面；用户提供的 34 页文件以私有副本完成实际界面点击、修改字号及保存重开验证，原文件和未修改页保持不变。测试副本、业务内容和个人文件不随源码或安装包上传。

## 使用与限制

打开 PDF → 编辑 → 点击文字框 → 修改／调整格式 → ⌘S 或另存为。请保留原文件。

普通文字型 PDF 优先复用原字体；缺字才嵌入替代中文字体。格式作用于整个文字框，不是 Word 式逐字排版。扫描图片、文字轮廓、复杂嵌套 Form 内容、缺少可靠字符映射的文件仍不能保证原文编辑。OCR 仅英文／基础拉丁字母，不支持中文扫描件。不是 Acrobat 的完整替代品。

Apple Silicon（M 系列）macOS，本地签名、未经 Apple 开发者公证。保留个人设置和旧版本；不关闭系统安全保护。
