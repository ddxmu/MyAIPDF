# MyAIPDF 0.1.8

“导出 PDF”的 Excel 项改名为 **Excel文档(.xlsx)**。重新实现按页面位置组织的 XLSX 导出，不再把表格和正文粗略提取到连续行里。

## 使用

打开 PDF → 导出 PDF → Excel文档(.xlsx) → 选择方式 → 导出 Excel。

- **可编辑单元格（默认）**：每页一个工作表，识别有边框表格，保留合并与空白格、行列尺寸、文字位置、原字体名称、字号、字重、颜色、底色、表格线、图片及打印分页。小数和百分比在无歧义时转为数值；前导零及长编号保持文字，公式文字不会执行。
- **原样保真（页面图像）**：200 dpi 整页图像保留字体外观和版式，正文与表格不能逐字编辑。

可编辑方式需要电脑安装原字体，否则 Excel 会替换。特殊或裁切等局部文字保留为图像，工作表标注“局部图像”；复杂、扫描或重叠等无法可靠映射的整页标注“图像”。图像部分不能逐字修改。不暴露原本被遮挡的字符，不悄悄漏掉未识别内容。PDF 与 Excel 排版方式不同，不承诺所有文档逐像素一致或完全可编辑；请核对内容和打印预览，修改长文字后也需检查布局。

所有转换都在本机进行，不上传文件，不修改 PDF、撤销历史或原文水印。一次最多 500 页、256 MB 图片；超限或不支持的页面尺寸明确提示。保留原有 Word 导出两种模式及其他 PDF、AI 功能。

自动化工具 `doc_export_office` 增加 XLSX 专用 `excel_mode`：`editable`（默认）或 `preserve`。错误模式、其他格式、混用 Word 参数和越界路径会被拒绝。

## 安装与更新

完整包保持 `MyAIPDF.dmg`；增量包 `MyAIPDF-0.1.8-from-0.1.7.delta.dmg` 仅接受未修改的正式 0.1.7 应用。菜单 → 帮助 → 关于 MyAIPDF → 检查更新，下载校验通过后可安装并重启；保留旧程序备份及个人设置，必须先保存未保存的 PDF，没有静默更新。

本机产物保存至桌面 MyAIPDF/0.1.8，历史版本不覆盖。适用于 Apple Silicon Mac，本地临时签名，未经 Apple 开发者公证；无需关闭系统安全保护。不安装原文专有字体，不上传用户测试文档或私有截图。继承 MIT OR Apache-2.0 及各开源依赖许可。
