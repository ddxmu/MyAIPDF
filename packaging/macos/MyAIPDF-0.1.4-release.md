# MyAIPDF 0.1.4

修复检查到新版却没有下载／安装按钮的问题。上一版只发布增量包，而 0.1.1／0.1.2 更新器只认识完整 `MyAIPDF.dmg`，导致升级入口不可用。本版按用户要求提供完整安装包，也保留 0.1.3 的增量升级路径。

- 完整 Apple Silicon Mac 安装包：`MyAIPDF.dmg`，包含完整 `MyAIPDF.app`、中文黑体、OCR 资源及许可；不需要旧版作为基础。
- 0.1.1／0.1.2：重新“检查更新” → “下载更新” → “安装并重启”，使用旧版已有按钮安装完整包。
- 0.1.3：原“下载增量更新”按钮选择 `MyAIPDF-0.1.4-from-0.1.3.delta.dmg`，校验后“安装并重启”。仅适用于未改动的 0.1.3。
- 0.1.4 之后：统一“下载更新”按钮，显示完整／增量类型及大小。有匹配增量时优先使用，否则使用可校验的完整包。没有可校验的安装包时不伪装可安装。
- 下载校验 SHA-256，安装检查应用标识、版本和深层签名。先准备副本，再替换并保留旧程序备份；设置与钥匙串不变。未保存 PDF 会阻止安装，不静默关闭，不在启动时联网检查。

桌面留存：`MyAIPDF/0.1.4/`；完整包另以 `MyAIPDF-0.1.4.dmg` 放在桌面 `MyAIPDF` 文件夹顶层，便于直接找到。保留旧版本，不自动替换当前正在使用的程序。

保留 0.1.3 的水印分析／选择删除、常用工具、AI 设置弹窗，以及中文排版和文字编辑。本次不扩展 PDF 编辑能力，原有扫描、轮廓文字、复杂嵌套内容等限制不变。没有内置 AI 模型或密钥。

适用于 M 系列 Mac；本地签名、未经 Apple 开发者公证。若 macOS 提示无法验证开发者，请使用系统提供的“打开”或“隐私与安全性”流程，不关闭系统安全保护。
