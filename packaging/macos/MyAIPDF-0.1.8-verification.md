# MyAIPDF 0.1.8 验证记录

日期：2026-10-08。macOS arm64，PrintCraft 0.2.1 基础；本地临时签名，未经 Apple 开发者公证。

## PDF 转 Excel

- 菜单显示为 `Excel文档(.xlsx)`；真实中文导出菜单点击、两种模式选择、取消及确认导出均有 UI 测试与渲染检查。
- 默认方式按 PDF 坐标映射为真实可编辑单元格，每页一个工作表。覆盖有边框表格、合并与空白格、字号／字重／颜色、背景填充、图片、行列尺寸、打印范围与分页；图片使用双单元格锚点，合并格边框只设置于周边，避免内部分割线和图片／表格漂移。
- 原字体名称保留，不安装或嵌入专有字体。字符列宽按正常样式字体换算，参考 [Open XML 列宽说明](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.spreadsheet.column?view=openxml-3.0.1)；缺失原字体、替代字体度量及不同表格软件仍会影响实际外观。
- 小数及百分比在无歧义时为数值，前导零和长编号保持文字，公式样式的 PDF 文字不会变成可执行公式。无外部链接或宏。容量、尺寸、图形与网格复杂度有上限；支持 1–500 页及最多 256 MB 图像，越界不静默缩放。
- 特殊、裁切或不能安全映射的局部文字使用可见图像裁片，工作表明确标为“局部图像”；复杂、扫描、重叠等整页使用标为“图像”的 200 dpi 页面。被遮挡的文字／原图像像素不会以原始内容偷偷导出。图像部分不可逐字修改。显式保真方式整页为图像，不冒充可编辑表格。
- 只读取导出专用工作副本；未保存的文字修改会纳入导出，原 PDF、脏标记与撤销历史不变。原有 Word 导出保留；相邻 immutability 测试固定时钟，避免 PDF 保存时间跨秒导致无关误报，生产时钟行为不改。
- 805 项原生测试通过，0 失败、5 项按原配置忽略；fmt、clippy（警告视为错误）、assets、layers、parity 通过。Office 能力仍为 partial，不承诺任意 PDF 的逐像素或全可编辑转换。wasm target 未安装，不声称 web 构建通过；高负载时跳过的性能测量不作性能结论。

## 私有文档与独立验证

用户指定的当前 12 页 A4 报告只在本机测试。应用 CLI 导出两种 XLSX，独立导入、检查与渲染；另用无界面 Office 渲染器输出为 12 页 A4（595.304 × 841.89 pt），重新查看全部页面。逐页检查表格、正文、Logo、合并格、边框、页码、标题间距和分页，没有此前粗略提取的连续行排版。QA 使用临时开源字体替代配置，不据此宣称专有源字体外观一致。

可编辑版本：242627 字节，12 个工作表、338 个有内容的真实单元格、277 个合并范围、41 张原始图片／局部或整页图像。第 2 页复杂目录为整页图像；第 3–6 页表格为可编辑格，部分页脚或符号保留为局部图像。表格中的真实百分比单元格经独立修改、保存、重新打开验证，原转换示例不带该测试改字。

保真版本：3446519 字节，12 张 200 dpi 整页图像，无可编辑正文；仅在本地 QA 保留，不与可编辑示例混淆交付。ZIP/XML 完整性、原字体名称、模式标记、公式与外部关系检查通过。
