# MyAIPDF 0.1.3

- 左侧新增“水印去除”：分析当前页或全部页、预览候选位置、勾选对象、二次确认删除、撤销，再手动保存。可处理明确标记的水印、独立文字、图片或图形；默认不自动勾选。文档改变后必须重新分析，过期选择不会执行。
- 支持常用灰色项：页面切换、多个 PDF／图片／文本创建、Excel 文字／表格提取、PPT 每页图片导出、扫描背景对比度／锐化、距离测量及可保存标注、文字／矢量转灰度、裁切标记、显式细线修复、基础 PDF/A 预检。云形、印章、附件、脚本控制台、文档脚本、空间占用分析原先已实现，本版修正目录状态与入口。
- AI 接口设置改为居中弹窗：有边框的 API 地址／密钥／模型输入框，清晰的接口与模型下拉框，明确的拉取、保存按钮。侧栏单独保留对话记录和问题输入。
- 默认接口地址为空。MyAIPDF 不安装、不运行本机 AI 模型；仅清理已知测试地址与虚构 QA 模型，保留其他接口。AI 仍仅在主动发送后请求，PDF 文字须授权，修改须确认，不自动保存原件。
- 后续只发布二进制增量包，不提供新完整 DMG 更新。精确匹配基础版本，校验旧程序、增量数据、合成结果和签名；旧程序备份及设置保留。无对应增量时停止，不退回完整下载。

## 从 0.1.2 升级

先保存并退出 MyAIPDF，打开 `MyAIPDF-0.1.3-from-0.1.2.delta.dmg`，双击“MyAIPDF增量安装”，选择现有 0.1.2 `MyAIPDF.app` 并确认。旧版更新器不认识增量格式，这次使用独立助手；新版之后从“帮助 → 关于 MyAIPDF → 检查更新 → 下载增量更新 → 安装并重启”更新。

包内没有完整 MyAIPDF.app，只包含已变更文件／二进制差分及增量安装助手。未变更的 OCR 模型等从本机旧版复用。只适用于未改动的 0.1.2 Apple Silicon 构建；其他基础版本会被拒绝。初次安装用户可先使用留存的 0.1.2 完整包，再应用本增量。

本地版本留存：桌面 / MyAIPDF / 0.1.3 /。保留此前版本。本地签名、未经 Apple 开发者公证；不关闭系统安全保护。

保留 0.1.2 的中文字体对齐及文字编辑。扫描件、轮廓文字、复杂嵌套内容和逐字混合排版仍有限制，不是 Acrobat 完整替代品。

## 功能边界

水印候选也可能是正文、标题、页眉 Logo；请逐项预览，仅选择你有权去除且确认为水印的对象。覆盖整页的扫描图片不会作为可删除对象，扫描像素里的水印不能独立剥离；复杂嵌套图形可能只能选择整个独立图形。本功能不是保密涂黑，增量保存仍保留 PDF 的旧修订数据；如需清除机密内容，请使用专业涂黑及完整重写流程。

Excel 是文字／表格提取，不还原所有版式；PPT 是页面图片，不能把原文当作可编辑幻灯片文字。扫描增强保留文字层，最多 100 页；转灰度仅覆盖直接 RGB/CMYK 文字与矢量，不转换 ICC／专色或扫描图片。基础预检不保证 PDF/A 完整合规。

多个文件创建支持 PDF、图片和 UTF-8 拉丁文本。新文本文件若包含本版创建器尚不支持的中文／其他字形，会明确拒绝，不生成丢字文件；可先转 PDF 再合并。这不影响已有 PDF 的中文文字编辑。

尚未实现的高级项仍保留真实状态：证书加密、可信时间戳、PS/EPS 导出、专业输出预览、地理定位、自动结构标签／阅读顺序、内嵌全文索引、文档动作以及 PDF/X、PDF/UA 和高级归档／辅助访问工作流。这些项目尚未实现，仍显示为不可用。
