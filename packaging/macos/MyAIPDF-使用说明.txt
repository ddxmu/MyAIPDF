MyAIPDF 中文 macOS 版 0.1.3

本版更新：AI 设置改为独立弹窗，输入框、模型下拉框和按钮有清晰边界；对话记录、问题输入分区显示。默认 API 地址为空，不安装或启动本机 AI 模型。已清理之前遗留的固定响应 QA 配置；保留其他真实接口设置。后续只发布匹配基础版本的增量更新，不回退下载完整包。
保留红紫渐变 DPF 图标和 0.1.2 的文字编辑、中文排版。界面黑体仅校正行距，按 OFL 保留名称要求使用 MyAI 内部名称，版权和许可保留；不影响 PDF 文档字体。

水印去除：左侧“水印去除” → 当前页／全部页面 → “分析水印” → “预览位置”检查候选 → 勾选要去除的对象 → “删除所选水印” → 确认删除 → ⌘S 保存或“另存为”。默认不勾选任何对象；可 ⌘Z 撤销。文档改变后必须重新分析，避免执行过期选择。
水印候选也可能是正文、标题或页眉 Logo，不能盲目全选。仅能删除可独立分离的文字、图片、图形及明确标记水印；扫描像素内的水印不能独立删除，整页扫描背景不列为删除对象。请仅处理你有权修改的文档。本功能不是保密涂黑，增量 PDF 保存仍保留旧修订数据。

灰色工具：本版补齐页面切换、多个 PDF／图片／UTF-8 文本合并创建、Excel 文字／表格提取、PPT 页面图片导出、扫描增强、距离测量与标注、文字／矢量转灰度、裁切标记、细线修复、基础 PDF/A 预检。云形、印章、附件、脚本控制台、文档脚本、空间占用分析修正为实际可用入口。
Excel 不保证原版式，PPT 每页为一张图片而非可编辑原文字；扫描增强只处理独立背景图并保留文字层，灰度转换不包括图片／ICC／专色，细线宽度按内容坐标计算。基础预检不是标准合规认证。证书加密、可信时间戳、PDF/X、PDF/UA、自动标签、阅读顺序、地理定位、内嵌索引等高级功能仍未完整实现，保留真实状态。
文本文件创建目前仅支持 UTF-8 拉丁文本；中文等未支持字形会明确拒绝，不悄悄变成问号。请先将这类文本转为 PDF 再合并，不影响已有 PDF 的中文文字编辑。

编辑文字：打开 PDF → 顶部“编辑” → 点击页面文字框 → 修改文字。左侧可调整整个文字框的字号、加粗、倾斜、颜色等。点击“应用修改”或 ⌘Enter 提交，⌘S 会先提交当前输入再保存，建议“另存为”保留原件。Esc／取消输入仅放弃尚未提交的输入；已经应用的调整可用 ⌘Z 撤销。
PDF 原字体能显示新文字时优先保留；原字体缺字或改变中文字重时，自动嵌入可用中文黑体的字形子集，保存重开后可继续编辑。中文长段落按文字框宽度换行，保留手动换行。缺字或保存失败会提示并保留输入；关闭和更新安装会检查未保存的输入草稿。
限制：扫描图片、轮廓文字、复杂嵌套内容或缺少字符映射的文件不能保证原文编辑；当前不支持框内逐字混合格式、任意系统字体选择或中文扫描件 OCR。不要将“可用”理解成所有 PDF／所有字体均已支持。

程序更新：菜单 → 帮助 → 关于 MyAIPDF，点击“检查更新”。若有适配当前版本的增量包，先点“下载增量更新”，再点“安装并重启”。仅获取 https://github.com/ddxmu/MyAIPDF 的正式版本；更新校验旧版、增量文件、新版文件及程序签名。在副本上合成，通过后才替换应用，并保留旧程序备份和个人设置。基础版本不匹配或文件被改动会停止，不下载完整包。请先保存所有未保存的 PDF。

从 0.1.2 首次升级到 0.1.3：保存并退出旧程序 → 打开 MyAIPDF-0.1.3-from-0.1.2.delta.dmg → 双击“MyAIPDF增量安装” → 选择原 0.1.2 的 MyAIPDF.app → 按提示安装。旧版更新器不支持增量格式，首次由独立助手安装；后续从新版关于页面更新。程序没有静默安装或关闭系统安全保护。

安装：将 MyAIPDF 拖到 Applications（应用程序）。本版适用于 M 系列芯片 Mac。
这是本地签名版，未经过 Apple 开发者公证。如果首次启动提示无法验证开发者，请在 Finder 里右键应用选择“打开”，或按“系统设置 → 隐私与安全性”的提示操作。不要关闭系统安全保护。

AI 使用：左侧“所有工具 → AI 助手” → “接口设置”，在弹窗中填写 API 地址和密钥，点击“拉取模型”，选择对话模型，再保存接口设置、完成设置。返回侧栏，在有边框的对话输入框中提问。
支持 OpenAI 兼容接口（GET /models、POST /chat/completions），例如 https://你的服务器/v1。可添加多个接口，也可手动填写模型 ID。接口服务费与模型权限由服务商决定，不包含免费密钥或额度。
密钥默认仅在本次会话使用，勾选保存才写入 macOS 钥匙串，不写入普通配置文件。

输入问题或 PDF 处理要求并发送。要总结／翻译文档，先勾选“发送 PDF 文字供 AI 分析”，再选择当前页或全文。全文最多发送前 150 页、6 万字，超过部分会提示截断。
AI 可提议旋转／移动／删除／插入页面、修改属性、填写表单、添加批注或书签。先核对操作方案，再点“确认执行”。一次方案是一个撤销步骤（⌘Z）。原文件不会自动保存，建议“另存为”保留原件。
切换文档或文档版本发生变化后，旧方案不会执行。模型返回的文件读写、代码执行等越权操作会被拒绝。

请核对 AI 输出。只有主动发送时才连接 API；PDF 原始文件不整份上传，只按授权提取文字。对话不写入本机配置，但服务商可能按其政策保留已提交内容。本机 PDF 崩溃恢复备份属于独立的本地数据。

基于开源 PrintCraft，并非 Adobe Acrobat 完整替代品。标注规划中的工具尚未全部实现。AI 翻译显示在对话框中，不会自动重排写回原文。自带 OCR 只支持英文／基础拉丁字母，不支持中文扫描件。
