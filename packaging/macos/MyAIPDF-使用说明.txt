MyAIPDF 中文 macOS 版 0.1.7

PDF 转 Word：导出 PDF → Microsoft Word → 选择转换方式 → 导出 Word。
“原样保真（页面图像）”为默认方式，以 200 dpi 页面图像保留版式、字体外观、表格、Logo、水印与分页；不能逐字编辑正文。
“可编辑文字（定位文本框）”把可识别的水平正文按原位置放入文本框，明确保留原字体名称、字号、颜色。电脑需安装原字体，否则 Word 会替代字体；复杂、旋转、透明、轮廓、扫描或未识别内容保留为页面图像。表格边框为背景图，不是原生 Word 表格；编辑较长内容不会自动重排其他文本框。
两种方式均在本机处理、不上传 PDF、不改动原文件。没有把整页图片冒充为可编辑正文。页面超出 Word 支持范围时停止并提示，不悄悄缩放；请保存后核对。保真模式保证固定页面排版，不保证不同 PDF 渲染器逐像素一致。

本版修复中文姓名／日期水印的字体解码，以及同一文字对象内多个独立位置的重复水印识别。分析列表优先展示文字水印，减少正文括号误判；按文字筛选可“选择匹配水印”，并用“下一处”检查不同位置。保留标题左侧返回箭头。扫描像素内或不能安全分离的嵌套水印仍不承诺自动去除。
AI 已开放应用内已实现的 PDF 工具：现有文字／图片编辑、页面、书签、表单、批注、链接、水印、OCR 等。输入“删除文字为……的水印”，方案会在本机核对候选并显示真实名称、数量、页数；先预览，再确认。读取／分析结果只在本机显示，可点“将结果填入提问”，再次发送才会提交至配置的接口。
这不是电脑系统权限：AI 不得读任意文件、访问其他文档、执行任意脚本或获取密码／私钥。导入／导出、另存为、打印、密码／证书及签名工作流由 AI 打开工具面板或对话框，文件、路径、凭据和最后执行由你选择。修改需确认，可撤销，不自动覆盖原文件。AI 也可单独提议撤销或重做。

保留 0.1.5 的以下功能：
PostScript / EPS：打开 PDF → 导出 PDF → PostScript / EPS → 选择格式、页码和分辨率 → 导出。PS 为多页文件，EPS 每页一个文件。此版输出页面图像，保留可见版式；文字和矢量转为 JPEG 像素，不保留可编辑文字、矢量或印刷色彩管理。
使用证书加密：保护 PDF → 使用证书加密 → 添加收件人的 .cer/.crt/.pem/.der 公钥证书 → 选择只读与打印或完全控制 → 确认对应私钥 → 另存加密 PDF。支持 1–16 个 RSA 2048–4096 位证书，AES-256；拒绝过期、尚未生效、仅签名或 CA 证书及已签名 PDF 重写。所有收件人使用同一权限设置。
打开加密副本时选择对应 .p12/.pfx 私钥文件，输入该文件的密码。私钥和密码不保存在设置中；普通保存和自动恢复文件保持证书加密。证书加密强制另存，不覆盖原 PDF。请核对证书指纹并保留原件；不联网验证吊销，权限限制依赖阅读器。此版仅支持 adbe.pkcs7.s5/AESV3、AES-256-CBC 的 RSA CMS 信封，不支持旧版 RC2/3DES CMS、EC 或硬件钥匙串解密，也不支持单独打开加密文件历史修订。

本版保留检查更新后的安装入口：发布完整安装包兼容旧版更新器，也发布从 0.1.6 升级的增量包。新版明确显示包类型，先“下载更新”，校验通过后再“安装并重启”。有匹配的增量包时优先使用，否则使用可校验的完整包。
保留 AI 独立设置弹窗和有边框的输入框／下拉框，对话记录、问题输入分区显示。默认 API 地址为空，不安装或启动本机 AI 模型；保留真实接口设置。
保留红紫渐变 DPF 图标和 0.1.2 的文字编辑、中文排版。界面黑体仅校正行距，按 OFL 保留名称要求使用 MyAI 内部名称，版权和许可保留；不影响 PDF 文档字体。

水印去除：左侧“水印去除” → 当前页／全部页面 → “分析水印” → 输入姓名／日期筛选 → “预览位置”／“下一处”检查候选 → 勾选或“选择匹配水印” → “删除所选水印” → 确认删除 → ⌘S 保存或“另存为”。默认不勾选任何对象；可 ⌘Z 撤销。文档改变后必须重新分析，避免执行过期选择。
水印候选也可能是正文、标题或页眉 Logo，不能盲目全选。仅能删除可独立分离的文字、图片、图形及明确标记水印；扫描像素内的水印不能独立删除，整页扫描背景不列为删除对象。请仅处理你有权修改的文档。本功能不是保密涂黑，增量 PDF 保存仍保留旧修订数据。

灰色工具：本版补齐页面切换、多个 PDF／图片／UTF-8 文本合并创建、Excel 文字／表格提取、PPT 页面图片导出、扫描增强、距离测量与标注、文字／矢量转灰度、裁切标记、细线修复、基础 PDF/A 预检。云形、印章、附件、脚本控制台、文档脚本、空间占用分析修正为实际可用入口。
Excel 不保证原版式，PPT 每页为一张图片而非可编辑原文字；扫描增强只处理独立背景图并保留文字层，灰度转换不包括图片／ICC／专色，细线宽度按内容坐标计算。基础预检不是标准合规认证。证书加密、可信时间戳、PDF/X、PDF/UA、自动标签、阅读顺序、地理定位、内嵌索引等高级功能仍未完整实现，保留真实状态。
文本文件创建目前仅支持 UTF-8 拉丁文本；中文等未支持字形会明确拒绝，不悄悄变成问号。请先将这类文本转为 PDF 再合并，不影响已有 PDF 的中文文字编辑。

编辑文字：打开 PDF → 顶部“编辑” → 点击页面文字框 → 修改文字。左侧可调整整个文字框的字号、加粗、倾斜、颜色等。点击“应用修改”或 ⌘Enter 提交，⌘S 会先提交当前输入再保存，建议“另存为”保留原件。Esc／取消输入仅放弃尚未提交的输入；已经应用的调整可用 ⌘Z 撤销。
PDF 原字体能显示新文字时优先保留；原字体缺字或改变中文字重时，自动嵌入可用中文黑体的字形子集，保存重开后可继续编辑。中文长段落按文字框宽度换行，保留手动换行。缺字或保存失败会提示并保留输入；关闭和更新安装会检查未保存的输入草稿。
限制：扫描图片、轮廓文字、复杂嵌套内容或缺少字符映射的文件不能保证原文编辑；当前不支持框内逐字混合格式、任意系统字体选择或中文扫描件 OCR。不要将“可用”理解成所有 PDF／所有字体均已支持。

程序更新：菜单 → 帮助 → 关于 MyAIPDF，点击“检查更新” → “下载更新” → “安装并重启”。页面明确显示完整包或增量包及大小。仅获取 https://github.com/ddxmu/MyAIPDF 的正式版本，并验证 GitHub SHA-256、应用标识、版本及程序签名；在副本上准备，通过后才替换应用，保留旧程序备份和个人设置。增量包还会校验整个基础版本和合成结果，若基础文件被改动则停止。请先保存所有未保存的 PDF；没有静默安装或启动时自动检查。

从 0.1.1／0.1.2 升级到 0.1.4：重新“检查更新”后，旧版会识别完整 MyAIPDF.dmg 并显示原有“下载更新”及“安装并重启”按钮。也可打开新完整安装包，将 MyAIPDF.app 拖入应用程序。0.1.3 可通过原有“下载增量更新”按钮升级；增量基础必须是未改动的 0.1.3。旧版本程序及安装包继续留存，新版本保存到桌面 MyAIPDF 文件夹。

安装：将 MyAIPDF 拖到 Applications（应用程序）。本版适用于 M 系列芯片 Mac。
这是本地签名版，未经过 Apple 开发者公证。如果首次启动提示无法验证开发者，请在 Finder 里右键应用选择“打开”，或按“系统设置 → 隐私与安全性”的提示操作。不要关闭系统安全保护。

AI 使用：左侧“所有工具 → AI 助手” → “接口设置”，在弹窗中填写 API 地址和密钥，点击“拉取模型”，选择对话模型，再保存接口设置、完成设置。返回侧栏，在有边框的对话输入框中提问。
支持 OpenAI 兼容接口（GET /models、POST /chat/completions），例如 https://你的服务器/v1。可添加多个接口，也可手动填写模型 ID。接口服务费与模型权限由服务商决定，不包含免费密钥或额度。
密钥默认仅在本次会话使用，勾选保存才写入 macOS 钥匙串，不写入普通配置文件。

输入问题或 PDF 处理要求并发送。要总结／翻译文档，先勾选“发送 PDF 文字供 AI 分析”，再选择当前页或全文。全文最多发送前 150 页、6 万字，超过部分会提示截断。
AI 可提议旋转／移动／删除／插入页面、修改属性、填写表单、添加批注或书签。先核对操作方案，再点“确认执行”。一次方案是一个撤销步骤（⌘Z）。原文件不会自动保存，建议“另存为”保留原件。
切换文档或文档版本发生变化后，旧方案不会执行。模型返回的文件读写、代码执行等越权操作会被拒绝。

请核对 AI 输出。只有主动发送时才连接 API；PDF 原始文件不整份上传，只按授权提取文字。对话不写入本机配置，但服务商可能按其政策保留已提交内容。本机 PDF 崩溃恢复备份属于独立的本地数据。

基于开源 PrintCraft，并非 Adobe Acrobat 完整替代品。标注规划中的工具尚未全部实现。AI 翻译显示在对话框中，不会自动重排写回原文。自带 OCR 只支持英文／基础拉丁字母，不支持中文扫描件。
