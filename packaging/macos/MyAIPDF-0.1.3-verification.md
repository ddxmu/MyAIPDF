# MyAIPDF 0.1.3 验证记录

验证环境：Apple Silicon macOS，2026-10-07。本地签名，未经过 Apple 开发者公证。未验证 Intel Mac、Windows 或 WebAssembly 构建。

## 自动检查

- 工作区 `fast-tests` 配置：771 项通过，4 项既有测试忽略，0 失败。该配置继承 release，关闭 LTO 以缩短测试编译时间。
- `cargo fmt --all --check`、release 全目标 Clippy（警告视为错误）通过。
- 资源许可检查通过：224 个仓库资源、6 个依赖内资源、22 个构建输入。功能证据表检查通过；34 个 crate 无分层违规。功能证据表仍有既有未覆盖自动化的条目，不代表完整 Acrobat 功能已通过验证。
- 生产构建：`printcraft`、`printcraft-cli`、`myaipdf-updater` release 构建通过；应用和增量助手通过严格签名检查。

## 实际文件与界面

- 原创测试 PDF 含正文及 DRAFT、KEEP-ME 两组水印。经分析、选择 DRAFT、确认删除、保存并重新打开后，独立 pypdf 提取验证只有 DRAFT 被移除；正文及 KEEP-ME 保留。Poppler 渲染前后文件并完成视觉检查。
- 自动测试覆盖确认取消、撤销、过期选择拒绝、共享内容流及 Form 隔离、扫描整页背景不作为删除目标，以及工具根目录边界。水印候选并不是自动判定为水印；扫描像素和复杂嵌套对象仍受限。
- Excel/PPT 导出经 openpyxl、python-pptx 独立读取，PPT 经 LibreOffice Impress 打开并转成可读 PDF。PPT 为页面图片，Excel 为文字／表格提取，不是完整可编辑版式转换。
- 新工具经自动化入口保存／重开验证；UI 测试覆盖实测拖拽、弹窗取消／应用、撤销及工具入口。扫描增强、矢量转灰度、细线修复、页面切换和裁切标记遵循发布说明的限制。
- 原创内容的原生界面截图检查覆盖水印侧栏、AI 设置与聊天、明暗主题、小窗口；800×600 与 1024×700 的保存／忘记密钥／完成设置按钮均在窗口内。
