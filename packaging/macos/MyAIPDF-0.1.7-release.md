# MyAIPDF 0.1.7

重点修复 PDF 转 Word 的排版：不再把零散文字强行猜成 Word 表格，避免列宽超页、错行、表格拆散和多出空白页。

## 使用

打开 PDF → 导出 PDF → Microsoft Word → 选择方式 → 导出 Word。

- **原样保真（页面图像，默认）**：每个 PDF 页面对应一页 Word，200 dpi 页面图像保留版式、字体外观、表格、Logo、水印和分页；正文不能逐字编辑。
- **可编辑文字（定位文本框）**：可识别的水平正文按原坐标放入 Word 文本框，保留字体名称、字号、字重、颜色；电脑须安装原字体，否则 Word 会替换。表格线及复杂、旋转、透明、裁切、符号字体、扫描或未识别内容保持为背景图。不是原生 Word 表格，不支持修改长文本后的全文重排。

两种方式都在本机处理、不上传文档、不改动原 PDF；不在转换时删除水印。页面尺寸超出 Word 支持范围会提示，不能偷偷缩放原稿。一次最多 500 页，图像总量最多 256 MB。保存后请核对；保真指固定页面外观，不保证不同 PDF 渲染器逐像素一致，也不能承诺任何 PDF 均能完全可编辑且字体不变。

自动化工具 `doc_export_office` 增加 DOCX 专用 `word_mode`：`preserve`（默认）或 `editable`。非 DOCX 或未知模式会被拒绝。保留已有 HTML/RTF 流式导出及其他工具。

## 更新与兼容

完整安装包名保持 `MyAIPDF.dmg`，兼容旧版检查更新入口；增量包为 `MyAIPDF-0.1.7-from-0.1.6.delta.dmg`，只接受未修改的正式 0.1.6 应用。

菜单 → 帮助 → 关于 MyAIPDF → 检查更新 → 下载更新 → 校验后安装并重启。保存未保存的 PDF 后才允许安装，保留旧程序备份和个人设置；没有后台自动升级。历史版本保留，新产物保存到桌面 MyAIPDF/0.1.7。

适用于 Apple Silicon Mac。本地临时签名，未经 Apple 开发者公证；不要求关闭 macOS 安全保护。继承 PrintCraft 的 MIT OR Apache-2.0 许可和各依赖许可。用户测试文档、字体资产和私人截图不上传发布。
